# Known limitations

- English is the only published active course. Japanese and Chinese are shown as coming soon.
- Original answer mappings include 52 ambiguous or multipart items marked for manual review. Only unambiguous supported items are automatically graded. Static answer files remain inspectable on a static host.
- Original Speaking and Writing rubrics do not define a universal numeric pass threshold. Imported external AI feedback can be scored against the stored rubric, but cannot prove a conversation occurred or certify proficiency. Text alone cannot establish pronunciation or audio-based listening evidence.
- ChatGPT practice is a manual export, conversation and import workflow. It requires an Internet connection and an ordinary ChatGPT session; no direct integration exists.
- Local data does not sync automatically and may be lost if browser storage is cleared or evicted. Export backups.
- Browser TTS and installation behavior vary by platform and installed voices. Offline ChatGPT and guaranteed offline TTS are unavailable.
- The repository has a deployment workflow; public deployment and physical-device testing must be verified separately.
